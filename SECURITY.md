# Security Policy

Profile repository for the `Hcmdz` GitHub account. Documentation, generated
graphics and workflow automation only. No shipped application code, no user
data collected, no supported-version matrix.

Vulnerabilities in the Android apps built under this account belong to their
own repositories, which carry their own policy and release process.

## Reporting

Spotted a leaked secret or a supply-chain issue (e.g. a compromised action or
CDN asset)? Contact the owner directly via the GitHub profile (`Hcmdz`)
instead of opening a public issue.
